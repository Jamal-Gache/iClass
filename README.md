# SchoolSims Player

A bilingual simulation player for training scenarios. Users navigate a branching story — setup, context, decision, outcome — in English or Spanish, with selectable character representation. Built with FastAPI + React/Vite.

## Project Structure

```
backend/
  main.py           # FastAPI server — scenario assembly + static serving
  scenario.json     # Bilingual linked-graph scenario data
  tts.py            # ElevenLabs TTS with file-based cache
  requirements.txt

src/                # React + TypeScript source
  components/
  hooks/

public/assets/      # Media: *.jpg, *.mp4, *.vtt

dist/               # Built frontend (generated by `npm run build`)

tests/
  verify_ui.mjs     # Puppeteer E2E — 15 screenshots across all states
  screenshots/      # Generated on test run
```

## Setup

### Prerequisites

- Python 3.11+
- Node.js 18+

### Backend

```bash
cd backend
python -m venv venv && source venv/bin/activate
pip install -r requirements.txt
```

**Optional TTS** — create `backend/.env` or `.env.local` at the repo root:

```
ELEVEN_LABS_API_KEY=your_key_here
ELEVEN_LABS_VOICE_ID=JBFqnCBsd6RMkjVDRZzb   # optional override
ELEVEN_LABS_MODEL=eleven_v4                   # optional override
```

TTS is off when no key is set; the UI falls back to silent playback.

### Frontend

```bash
npm install
```

## Running

### Dev (hot reload)

```bash
# Terminal 1 — backend on :8000
cd backend && uvicorn main:app --port 8000 --reload

# Terminal 2 — Vite dev server on :5173
npm run dev
```

Vite proxies `/api` and `/tts` to `:8000`. Open `http://localhost:5173`.

### Prod (FastAPI serves built frontend)

```bash
npm run build                              # outputs to dist/
cd backend && uvicorn main:app --port 8000
```

Open `http://localhost:8000`.

## API

| Method | Path | Description |
|--------|------|-------------|
| `GET` | `/api/options` | Supported languages and ethnicities |
| `GET` | `/api/simulation?lang=en&ethnicity=black` | Scenario nodes + media paths for a session |
| `POST` | `/api/scenario/{lang}` | Persist edited scenario back to `scenario.json` |
| `POST` | `/api/tts/preload` | Pre-generate TTS audio for a set of slide texts |

---

## Simulation Flow

```
Setup → Context → Text+Image → Video → Decision → Outcome A or B → Summary → Restart
```

- **Language**: English (`en`) or Spanish (`es`) — affects all text and video.
- **Ethnicity**: `black` or `east_asian` — changes character photo and video only; no effect on text, roles, or outcomes.
- **Decision (Slide 4)**: Option A commits to the deadline; Option B proposes a phased pilot. Summary reflects the chosen path.

## E2E Verification

Requires the prod server running on `:8000` (build + start as above).

```bash
cd tests && npm install
node verify_ui.mjs --headless
```

Writes 15 screenshots to `tests/screenshots/` covering all slides, both choices, multilingual paths, and the error/retry state.

## Scenario Editing

`backend/scenario.json` holds all slide content in both languages. The `POST /api/scenario/{lang}` endpoint saves edits back to disk. Structure:

```json
{
  "start_node_id": "context",
  "en": { "nodes": { ... }, "ui": { ... } },
  "es": { "nodes": { ... }, "ui": { ... } }
}
```
